# Synentra Integrations

Synentra provides comprehensive integration capabilities with various enterprise tools and services to enable secure, observable, and policy-governed AI agent operations.

## Available Integrations

### Authentication

#### [Agent Authentication](./security/authentication)
JWT-based authentication supporting Keycloak, Auth0, and Azure AD.

**Use Cases:**
- Authenticate AI agents with JWT tokens
- Implement role-based access control
- Integrate with enterprise identity providers
- Track agent identity for audit trails

**Setup Time:** ~30-45 minutes (varies by provider)
