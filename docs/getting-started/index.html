Getting Started

Welcome to the Getting Started guide! This page will walk you through the essential steps to begin using the Synentra system. Whether you're a first-time user or returning for a refresher, you'll find everything you need—from initial setup and installation to key features and usage tips. Let’s get you up and running quickly and confidently. Synentra is designed with flexibility and ease of adoption in mind, supporting multiple installation methods to suit different environments and user preferences.

📄️Install Synentra CLI

For those who prefer automation, scriptability, the Synentra CLI provides a powerful way to install, configure, and manage Synentra with a few simple commands. This method is ideal for DevOps pipelines, infrastructure‑as‑code scenarios, and repeatable deployment patterns.

📄️Initialize Synentra Localy

For those who prefer automation, scriptability, the Synentra CLI provides a powerful way to install, configure, and manage Synentra with a few simple commands. This method is ideal for DevOps pipelines, infrastructure‑as‑code scenarios, and repeatable deployment patterns.

📄️Initialize with Docker

Initialize a local Synentra environment using Docker. The Synentra CLI automatically downloads the appropriate container image, creates the container, and starts the gateway.
