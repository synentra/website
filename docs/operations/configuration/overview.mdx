# Configuration Overview

Synentra uses the standard **ASP.NET Core configuration system** (`appsettings.json`, environment variables, user secrets, Azure Key Vault).

---

## Top-Level Sections

| JSON Key | Description |
|---|---|
| `System` | Server, storage, rate limiting, circuit breaker |
| `Security` | Agent security provider and quarantine mechanism |
| `Policy` | Policy engine provider selection |
| `Semantic` | Semantic/LLM provider selection |
| `HumanInTheLoop` | HITL thresholds and timeouts |
| `Observability` | Logging sinks |
| `SecretManagement` | External secret provider |

---
